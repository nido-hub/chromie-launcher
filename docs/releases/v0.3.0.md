## Langues, patches client et addons communautaires

### Nouveautés

- Interface disponible en **anglais, français et italien**, avec anglais par défaut. Le changement de langue est immédiat et conservé au prochain lancement, même sans dossier de jeu configuré.
- Nouvel onglet **Client patches** : installation du **Patch Y non-HD ou HD**, avec téléchargement MEGA intégré, confirmation de la variante et contrôle de l'intégrité (MAC MEGA, SHA-256 et format MPQ).
- Sauvegarde du patch existant avant remplacement, récupération des transactions interrompues et blocage de l'installation lorsque WoW est ouvert. Les deux variantes sont mutuellement exclusives.
- Catalogue enrichi à **133 packs** : ajout de **Chromie Wishlist 1.2.0** et **LootRolls / LootSummary 1.1.0** dans la catégorie ChromieCraft. AtlasLoot est installé comme dépendance requise de Chromie Wishlist s'il manque.
- Prise en charge de plusieurs dépôts d'addons avec révisions figées et vérification des empreintes propres à chaque source.
- Icône ChromieCraft intégrée à l'exécutable Windows, à la fenêtre principale et aux confirmations.

### Installation

1. Télécharger **`ChromieLauncher-0.3.0-win-x64.zip`** ci-dessous.
2. Extraire **tout le ZIP dans un dossier réservé au launcher**, distinct de la racine du jeu. Pour remplacer une ancienne version, fermer d'abord le launcher.
3. Lancer **`ChromieLauncher.exe`**, puis sélectionner le dossier contenant `Wow.exe` dans les paramètres si nécessaire.

**Windows x64 · .NET 10 Native AOT · Aucun runtime .NET à installer.** Conserver les DLL du ZIP à côté de l'exécutable. L'empreinte SHA-256 est fournie dans le fichier `.sha256`.

### Validation et limites

- **86 tests automatisés** couvrent notamment les langues, les sources communautaires, les téléchargements et les transactions. Le workflow de publication effectue aussi une compilation Native AOT et un contrôle desktop dans les trois langues.
- Les patches sont téléchargés séparément, pas inclus dans le ZIP. Choisir explicitement la variante adaptée au client HD/non-HD et fermer WoW avant installation. Les contrôles d'intégrité ne constituent pas un test en jeu.
- Les addons de l'archive WoWGaming restent une **archive historique**, pas une sélection actuellement maintenue ou recommandée individuellement par ChromieCraft. Les sources communautaires sont également figées ; aucune mise à jour silencieuse des addons manuels.
- Les sauvegardes sont conservées ; aucun réglage `WTF` n'est modifié. Les procédures de restauration manuelle sont documentées dans le README.
- L'auto-update du launcher **n'est pas encore activé pour la distribution** : le flux signé et la clé publique d'éditeur ne sont pas configurés. Télécharger cette version depuis GitHub Releases.
- L'exécutable n'est pas signé avec un certificat Authenticode ; Windows peut afficher un avertissement SmartScreen.
- Projet communautaire indépendant, non affilié à ChromieCraft. Les mentions et licences des ressources graphiques sont incluses dans le ZIP.
