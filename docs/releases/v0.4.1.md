## Mise à jour du launcher en un clic

### Nouveautés

- Le **numéro de version en haut à droite** devient le point d’accès aux mises à jour du logiciel et signale une nouvelle version disponible.
- Une seule confirmation **Mettre à jour et redémarrer** lance le téléchargement, la vérification, le remplacement et le redémarrage automatiques. Plus besoin de télécharger et d’extraire les prochains ZIP à la main.
- La vérification au démarrage ne lance aucun téléchargement ni redémarrage et n’ouvre pas de confirmation. L’utilisateur garde le choix du moment de la mise à jour.
- Le flux officiel GitHub est utilisé par défaut, y compris si les anciens paramètres contiennent une URL vide. Le choix d’un autre flux signé reste dans les paramètres avancés.
- Interface disponible en anglais, français et italien. Les addons, les paramètres du jeu et les préférences du launcher sont conservés.

### Sécurité

- Première version distribuée avec la **clé publique de signature intégrée** et le manifeste signé **`update.json`** publié avec le ZIP.
- Signature RSA/SHA-256 du manifeste et empreinte SHA-256 du ZIP vérifiées avant installation. Une mise à jour non signée, corrompue ou plus ancienne est refusée.
- Annuler le téléchargement ou rencontrer une erreur de téléchargement laisse l’application ouverte et les fichiers installés intacts. Les fichiers du launcher remplacés sont sauvegardés ; un échec de remplacement déclenche le retour arrière.
- La clé privée reste dans un secret GitHub Actions et n’est pas distribuée avec l’application.

### Installation de cette première version configurée

Les versions **0.4.0 et antérieures** n’embarquent pas la clé publique : **un dernier téléchargement manuel est nécessaire pour passer à 0.4.1**.

1. Télécharger **`ChromieLauncher-0.4.1-win-x64.zip`** ci-dessous.
2. Fermer le launcher, puis extraire **tout le ZIP dans son dossier réservé**, distinct de la racine du jeu.
3. Lancer **`ChromieLauncher.exe`**. Les futures versions pourront utiliser le bouton intégré.

**Windows x64 · .NET 10 Native AOT · Aucun runtime .NET à installer.** Les DLL du ZIP doivent rester à côté de l’exécutable. Le fichier `.sha256` fournit l’empreinte du ZIP ; `update.json` est destiné au launcher, pas à une installation manuelle.

### Validation

- **132 tests automatisés**, incluant le flux officiel par défaut, la clé publique embarquée et les traductions du nouveau parcours.
- Vérification de la correspondance clé privée / clé publique, signature et validation d’un manifeste en développement.
- Compilation Native AOT et contrôle desktop dans les trois langues : états du bouton version / mise à jour / redémarrage, navigation et fonctionnalités existantes, sans modification du jeu.

La mise à jour du **launcher** reste distincte de celle des **addons**. L’exécutable n’est pas signé avec un certificat Authenticode ; Windows peut afficher un avertissement SmartScreen. Projet communautaire indépendant, non affilié à ChromieCraft.
