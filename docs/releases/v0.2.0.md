## Un launcher aux couleurs de ChromieCraft

Cette version reprend l’identité visuelle du site ChromieCraft dans une véritable application desktop Windows :

- Fond illustré, emblème et logo ChromieCraft.
- Titres **Marcellus SC** et texte **Roboto Condensed**, embarqués pour fonctionner hors ligne.
- Palette noire, dorée et bleu glacier ; boutons encadrés et navigation horizontale.
- Mode compact adapté aux fenêtres de 1100 × 760 pixels.

### Gestion des addons

- Détection des addons déjà installés, recherche et catégories.
- Bibliothèque de **131 packs** issus de l’archive WoWGaming référencée par ChromieCraft.
- Installation avec dépendances, contrôle des téléchargements et confirmation avant remplacement.
- Sauvegardes avant remplacement ou désinstallation ; aucun changement des réglages `WTF`.
- Lancement de `Wow.exe` depuis l’application.

### Installation

1. Télécharger **`ChromieLauncher-0.2.0-win-x64.zip`** ci-dessous.
2. Extraire **tout le ZIP dans un dossier réservé au launcher**, distinct de la racine du jeu.
3. Lancer **`ChromieLauncher.exe`**, puis sélectionner le dossier contenant `Wow.exe` dans les paramètres si nécessaire.

**Windows x64 · .NET 10 Native AOT · Aucun runtime .NET à installer.** Les DLL du ZIP doivent rester à côté de l’exécutable. L’empreinte SHA-256 est fournie dans le fichier `.sha256`.

### Points importants

- **Version précoce du projet** : les 35 tests du moteur et le contrôle de navigation desktop sont exécutés avant la publication. La compatibilité des addons n’est pas testée en jeu.
- Le catalogue est une **archive historique**, pas une liste d’addons actuellement maintenus ni de recommandations individuelles de ChromieCraft. Une version proposée peut être plus ancienne que celle déjà installée.
- La mise à jour intégrée du launcher est implémentée, mais **n’est pas encore activée pour la distribution** : il manque le flux de manifestes signés et la clé publique d’éditeur. Cette release ne prétend pas fournir un auto-update opérationnel.
- L’exécutable n’est pas signé avec un certificat Authenticode : Windows peut afficher un avertissement SmartScreen. Le SHA-256 ne remplace pas une signature d’éditeur.
- Projet communautaire indépendant, non affilié à ChromieCraft. Les marques et visuels restent la propriété de leurs ayants droit. Les mentions et licences des polices sont incluses dans le ZIP.
